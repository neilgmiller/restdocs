# Plan 03-01: Render asyncResponse Section in rest_api_doc.vm

**Phase:** 3 — HTML Rendering
**Requirements:** HTML-01, HTML-02, HTML-03
**Estimated size:** ~25 lines template diff, ~80 lines test

---

## Goal

Add an "Async Response (via getAsyncJobStatus)" section to the root-level `rest_api_doc.vm`
template. The section renders immediately after the existing Response section for methods whose
`asyncResponse` is non-null. Methods without `asyncResponse` are unaffected. Add an integration
test that drives `DocGenerator` end-to-end and asserts the HTML output.

---

## Context Prerequisites

Read before touching any code:
- `rest_api_doc.vm` (root-level) — production template; DocGeneratorCommand defaults to
  `File(user.dir, "rest_api_doc.vm")`, confirmed in `DocGeneratorCommand.kt:52`
- `src/main/java/com/giffardtechnologies/restdocs/htmlgen/ObjectInspectionHelper.kt` — has
  `hasFields(typeSpec: TypeSpec)`, `getFields(typeSpec: TypeSpec)`, `isTypeRef(typeSpec: TypeSpec?)`
  that work with `storage.Response` (subclass of `TypeSpec`) via Velocity's method dispatch
- `src/main/java/com/giffardtechnologies/restdocs/DocGenerator.kt` — entry point for the
  integration test; takes `sourceFile`, `templateFile`, `outputFile`
- `src/test/resources/async-response-smoke-test.yaml` — existing fixture with all three cases
  (pureAsyncMethod, mixedAsyncMethod, syncMethod); reuse as-is for HTML testing

**Template resolution confirmed:** `storage.Method.asyncResponse` is accessible in Velocity as
`$method.asyncResponse` (Kotlin getter `getAsyncResponse()`). Non-null evaluates truthy in
`#if`. `Response` extends `TypeSpec`, so `$helper.hasFields($method.asyncResponse)` and
`$helper.getFields($method.asyncResponse)` dispatch to the `TypeSpec` overloads correctly.

## Tasks

### Task 1 — Modify `rest_api_doc.vm`: add asyncResponse section

In the methods loop, after the closing `</ul>` of the Failure Codes section and before `</section>`,
add the async response block. The current `</section>` that closes the method ends the method block.

**Current (lines 158–172):**
```velocity
                    <h5>Response</h5>
                    <p>$link.type($method.response)</p>
                    <h5>Success Codes</h5>
                        <ul>
        #foreach( $code in $method.successCodes )
                            <li>$code</li>
        #end
                        </ul>
                    <h5>Failure Codes</h5>
                        <ul>
        #foreach( $code in $method.failureCodes )
                            <li>$code</li>
        #end
                    </ul>
                </section>
```

**Replace with** (add the `#if ($method.asyncResponse)` block between Failure Codes and `</section>`):
```velocity
                    <h5>Response</h5>
                    <p>$link.type($method.response)</p>
                    <h5>Success Codes</h5>
                        <ul>
        #foreach( $code in $method.successCodes )
                            <li>$code</li>
        #end
                        </ul>
                    <h5>Failure Codes</h5>
                        <ul>
        #foreach( $code in $method.failureCodes )
                            <li>$code</li>
        #end
                    </ul>
        #if ($method.asyncResponse)
                    <h5>Async Response (via getAsyncJobStatus)</h5>
                    <p>Content appears in the <code>jr</code> field when <code>jobStatus</code> is <code>0</code>.</p>
            #if ($helper.hasFields($method.asyncResponse))
                    <table>
                        #fieldheaders
                #foreach( $field in $helper.getFields($method.asyncResponse) )
                        #fieldrow( $field )
                #end
                    </table>
            #elseif ($helper.isTypeRef($method.asyncResponse))
                    <p>$link.typeSimple($method.asyncResponse.typeRef)</p>
            #end
        #end
                </section>
```

### Task 2 — Write `DocGeneratorAsyncHtmlTest`

Create `src/test/kotlin/com/giffardtechnologies/restdocs/htmlgen/DocGeneratorAsyncHtmlTest.kt`.

**Setup:** In a `@BeforeAll` (companion object), call `DocGenerator(false).generate()` once and
capture the HTML as a string.

```kotlin
package com.giffardtechnologies.restdocs.htmlgen

import com.giffardtechnologies.restdocs.DocGenerator
import org.junit.jupiter.api.Assertions.assertFalse
import org.junit.jupiter.api.Assertions.assertTrue
import org.junit.jupiter.api.BeforeAll
import org.junit.jupiter.api.Test
import org.junit.jupiter.api.TestInstance
import org.junit.jupiter.api.io.TempDir
import java.io.File

@TestInstance(TestInstance.Lifecycle.PER_CLASS)
class DocGeneratorAsyncHtmlTest {

    private lateinit var html: String

    @TempDir
    lateinit var tempDir: File

    @BeforeAll
    fun renderHtml() {
        val yamlFile = File(javaClass.classLoader.getResource("async-response-smoke-test.yaml")!!.toURI())
        val templateFile = File(System.getProperty("user.dir"), "rest_api_doc.vm")  // absolute; parentFile must be non-null for VelocityEngine
        val outputFile = File(tempDir, "out.html")
        DocGenerator(false).generate(yamlFile, templateFile, outputFile, DocGenerator.Options(false))
        html = outputFile.readText()
    }
    // ... tests below
}
```

**Tests to write:**

**(a) Async section heading appears for pureAsyncMethod**
```kotlin
@Test
fun `async response section heading appears for async method`() {
    assertTrue(html.contains("Async Response (via getAsyncJobStatus)"),
        "HTML should contain the async section heading.\nHTML:\n$html")
}
```

**(b) Prose note contains jr and jobStatus**
```kotlin
@Test
fun `async response prose note references jr and jobStatus`() {
    assertTrue(html.contains("jr"), "HTML should contain 'jr'.\nHTML:\n$html")
    assertTrue(html.contains("jobStatus"), "HTML should contain 'jobStatus'.\nHTML:\n$html")
}
```

**(c) pureAsyncMethod fields appear — resultUrl and completedAt**
```kotlin
@Test
fun `pure async method fields are rendered in the async section`() {
    assertTrue(html.contains("resultUrl"), "HTML should contain resultUrl field.\nHTML:\n$html")
    assertTrue(html.contains("completedAt"), "HTML should contain completedAt field.\nHTML:\n$html")
}
```

**(d) mixedAsyncMethod field appears — analysisResult**
```kotlin
@Test
fun `mixed async method field is rendered in the async section`() {
    assertTrue(html.contains("analysisResult"),
        "HTML should contain analysisResult field.\nHTML:\n$html")
}
```

**(e) Regression: syncMethod output does not contain async section**

The syncMethod section in the HTML appears between the `<h3 id="...">` for the syncMethod URI and
the next `</section>`. Since we can't easily extract per-method HTML, assert the total count of
"Async Response" occurrences equals 2 (one for pureAsyncMethod, one for mixedAsyncMethod):
```kotlin
@Test
fun `async response section does not appear for sync method`() {
    val count = html.split("Async Response (via getAsyncJobStatus)").size - 1
    assertTrue(count == 2,
        "Expected exactly 2 async response sections (pureAsync + mixedAsync), got $count.\nHTML:\n$html")
}
```
