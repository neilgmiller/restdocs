<objective>
Build the warningEmitter channel through the entire Jackson validation infrastructure: Validatable 2-arg overload, ValidationModule constructor, ValidatingBeanDeserializerModifier constructor, ValidatingDeserializer constructor (all three factory sites), and createMapper signature.

Purpose: VALID-03 warnings can only be emitted if there is a channel from validate() up to the caller. Currently validate() can only throw. This plan adds that channel as a Kotlin function-type parameter threaded through the construction chain per D-01 and D-02. The design uses defaulted no-op lambdas at every level so existing callers require zero changes.

Output: Five files modified. The warning channel exists and is correctly propagated — including through the two Jackson factory sites (createContextual/replaceDelegatee) that would otherwise silently drop it on nested object deserialization.
</objective>
